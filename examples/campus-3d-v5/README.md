# 课程学院 · 教室光照与互动 v5

本轮把教室做成可进入、可切换采光和设备状态的完整样板。真实三维场景保持连续通行；图片均为实际浏览器渲染，未用生成图片替换建筑。

## 给 A/B 的参考入口

这是完整可运行的独立 3D 样板：真实几何、门窗洞口、室内桌椅、行走/寻路/碰撞、可操作门、喷泉、卷帘、照明和投影设备。已附构建产物和本地素材，运行只需 Node.js（建议与主站一致使用 22.12 或更新版本）；不用安装 Blender、Python、NVIDIA 工具或 npm 依赖。

首次获取仓库后，进入本目录运行：

```powershell
node server.mjs
```

浏览器打开 <http://127.0.0.1:4183/?view=classroom>。Windows 也可双击 `启动课程学院.cmd`。这个地址是运行者自己的电脑，不是负责人电脑的远程访问地址。端口被占用时，可在本终端设置 `$env:PORT='4193'` 后执行 `node server.mjs`，并用相应端口访问。

先看 `src/architecture.js`、`src/classroom.js`、`src/terrain.js` 的几何与命名，再看 `src/app.js` 的交互、`src/rendering.js` 和 `src/baked-lighting.js` 的光照处理。不要为自己的板块直接复制整套 renderer 和主循环到主站，场景接口由负责人统一接入。

本示例的课程练习和本机笔记是演示路径，未接主站真实账号/题库/多人服务。发布此参考不会改变主站默认页面。已有验证报告是样板制作时的记录，本次上传另执行复制完整性与适用回归检查，不把旧报告当作所有设备的性能保证。

## 启动与操作

双击 `启动课程学院.cmd`，访问 **http://127.0.0.1:4183/**。本机需要 Node.js，运行包已经构建，不必安装 npm 依赖。此目录为独立示例，主站仍按仓库原说明启动。

点击顶部「教室」观察，然后选择「开始漫游」。WASD / 方向键移动，拖动看向，J / L 转向，E 操作附近物体，Esc 站起或关闭面板，V 返回外观。

- 门边墙面开关：E 开关教室照明。
- 窗边：E 放下或收起三幅卷帘。
- 讲台旁：E 开启或结束投影演示，幕布、卷帘和照明联动。
- 座位旁：E 入座，视角平滑过渡，再按 E 进入课程、练习和笔记。
- 右下「教室设备」：随时选择「日光自习 / 课堂讲授 / 投影演示」，入座后也能操作。

投影演示保留 18% 的照明，方便辨认过道。单独的照明、卷帘和投影按钮也可分别操作。右下仍有自适应画质、流畅优先和细节优先。

学习笔记保存在浏览器本机。端口变更意味着 4182 与 4183 分别使用各自的浏览器存储；旧版本的记录未删除。

## 实际完成的改进

使用 Blender 4.5.3 LTS / Cycles，对实际模型执行漫反射光照烘焙，生成三张 **2048×2048 HDR** 图集：日光开帘、日光闭帘、室内 LED。每组使用 512 采样上限、六次漫反射反弹，并对浮点光照图集做 HDR 降噪。UV0 保留木材、石材和粉笔等材质；独立的 UV1 保存光照。

浏览器读取这三组结果，随卷帘和照明状态混合。接收烘焙的表面不再重复叠加实时漫反射照明；门、卷帘与室外仍使用缓存的实时阴影。日光和灯光分别校准了显示强度（3.0 与 0.65），并非经过实测照度标定的工程照明分析。

家具与构造补充了桌脚调节垫、椅脚保护套、书本封面和页层、桌面笔、讲台电脑、空调风口及黑板上的教学内容。卷帘和投影幕为可运动的真实几何。

## 重建与复现

只看效果无需安装依赖。修改源码后执行 `npm ci`、`npm run build`。应用与寻路 Worker 必须一起构建。`npm start` 启动 4183 服务。

用 Blender 4.5.3 重做光照：

```powershell
blender --background --factory-startup --python bake_lighting.py -- --size 2048 --samples 512
```

默认使用 NVIDIA OptiX；没有 NVIDIA GPU 时加 `--cpu`。脚本会覆盖本目录烘焙文件和同名 `.blend`，编辑前请另存。修改几何后，应先从 `?bakeSource=1` 页面导出新的输入模型，再重新烘焙；仅改动浏览器里的几何不会自动更新已有图集。

## 当前边界

这是实时质量样板，尚未达到照片级。卷帘中间位置采用开帘和闭帘结果的连续混合，灯光图集按独立贡献相加；不等同于逐帧路径追踪。投影幕本身发光，尚未烘焙其对桌椅的光线反弹；门运动、人物和新移动物体也不会自动重新计算静态间接光。

当前开放门厅和一间教室，上层仍为外观配景。本示例独立存放，未改主站默认业务入口。素材来源和授权沿用 `assets/sources.json` 与 `licenses/`；天空、灰砖、木材等来自 Poly Haven。黑板和投影课程内容为本项目绘制的教学图案。
