# 窗边桌椅 R1：局部烘焙样板交接（一页）

**用途：资产与接入准备，没有独立 lightmap UV、没有烘焙，不是照片级交付。** 总策划制作 UV／光照，C 后续按确认方案接入；本轮不改运行场景、#41 测试或 A/B/D。

**版本／入口。** 基于 main `38de7b5d12a08e0b333769075f5f49b3f944a6c5`；运行几何／材质基线 `ed40ec23998352bd6060f797cc834afe2944efc2`，两者图书馆运行文件一致。[版本与资源校验](version-audit.json)。执行 `node examples/library-3d/server.mjs`，打开 `/examples/library-3d/?view=sample`（默认 4196，本轮预览 4896）。已验收原件仍在 `../../assets/wenku-library.glb`、`../../Library_Editable.blend`，SHA 与第四轮清单一致，未覆盖或重新导出全馆。

**可独立处理资产。** [r1-local.glb](r1-local.glb) 直接裁取原 GLB，166 个网格节点、17 种材质、14 张内嵌图像。新局部工程 `R1_Local_Editable.blend` 在本轮交付目录，亦可用 [prepare-r1-blender.py](prepare-r1-blender.py) 从本文件重建；按角色分集合、三台相机、无渲染灯／world，先用材质预览检查。Blender 展开 4480 片原树叶后共 4645 个网格，14 张图像全部打包，已保存并实际重开。未将新的大 Blender 文件加入 Git。

**材质／资源。** [逐对象清单、范围和材质定义](objects-and-materials.json)、[灯光与玻璃参数](lighting-and-cameras.json)、[资源核验](asset-audit.json)。所有所用 GLB 图像内嵌、材质语义与原件一致；外部 HDR／原始 PBR 的路径与 SHA 见版本清单。Blender 不支持的既有 `EXT_materials_bump` 已由准备脚本恢复同一织物高度图并打包，不声称两引擎像素相同。样板玻璃保留 12mm／transmission 0.96；透明面不作为 lightmap 接收面。LED 为发光材质，非实时面光，初始工程单列且排除渲染；实时补光参数只记录，不自动转换为烘焙灯。
