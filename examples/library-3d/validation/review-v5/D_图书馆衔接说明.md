# 图书馆现状与 D 衔接资料

本轮 C 保留 `examples/library-3d/` 独立页，不将其改写成 createDistrict 公共插件。以下为现有接口和坐标事实，跨模块接入与回归仍由总策划和 D 安排。

## 入口、返回及资源

- 主站地点 ID：`wenku`。资料页按钮、首页地点入口指向图书馆独立页；返回为 `../../index.html#wenku`。不要把它替换成未提供的插件 API。
- 共享 PBR／HDR：`examples/campus-3d-v5/assets/`。图书馆源码通过相对 URL 访问既有素材。
- 馆藏：`js/wenku.js`、`js/wenku_cat.js` 和 `data/pdf/`。保留实际源链接；外站托管、404 与不支持页内阅读的格式仍需明确反馈。
- PDF Worker：`examples/library-3d/vendor/pdfjs/pdf.worker.min.js`。须保持同源可访问、生产子目录路径和后端白名单，不将原始源码或私有服务端目录一起开放。
- 登录及私有资料：沿用主站同源存储与 WG_API／WG_DEPLOY 配置，没有新账号体系。跨域或改端口不会自动共享 localStorage。复验使用独立数据目录及临时账号。
- 页面生命周期：隐藏时暂停渲染，非 bfcache 离开时 dispose，bfcache 返回时恢复；本轮新增局部阴影与诊断材质资源纳入释放。专项验证了显式 dispose 后帧计数停止。接入后返回焦点、跨板块状态与物理手机仍由 D 按实际总装环境复测。

## 坐标和地面

浏览器／GLB 坐标为米、Y 向上，建筑中心在原点，主入口朝 +Z。Blender 导入后采用 Z 向上，检查相机已做对应坐标转换。

| 对象 | 当前值 |
|---|---|
| 建筑主体 | 24m（X）×18m（Z），主体墙线 X=±12、Z=±9 |
| 室内地面顶面 | Y=0；基础地板 24.4×18.4m |
| 门前铺装顶面 | Y=-0.02m；与室内约 20mm 高差，未建真实缓坡 |
| 占位场地地面顶面 | Y=-0.31m，场地平面 100×80m，属于当前独立页占位环境 |
| 门中心／净宽 | X=0、Z=9；宽 2.8m |
| 漫游初始点 | `[0,0,14]`，朝 -Z；位置碰撞为平面查询，不模拟坡面高度 |
| 中央通道 | 标称宽 3m；保持入口和书架、座位 approach 可达 |
| R1 阅览桌中心 | `[6.6,0,-4.5]`，台面 3.8×1.2m，顶约 0.778m |
| R1 椅碰撞 | 0.54×0.60m；其余 R2 椅仍为 0.54×0.55m |

不要在总装中把独立页的占位大地面直接叠加为另一整片校园地面。本轮未确定总装平移、旋转及统一高程；以上衔接由总策划和 D 决定，C 未设计全校园。

## 样板相机、灯光和模型

| 视角 | eye | target | 纵向 FOV |
|---|---|---|---|
| 窗边样板 | `[2.7,1.7,-5.2]` | `[9,1.25,-4.6]` | 55° |
| 单椅检查 | `[4.55,1,-7.1]` | `[5.62,0.48,-5.63]` | 55° |
| 树冠近景 | `[23,3,4]` | `[16,3.6,-4]` | 55° |
| 树冠远景 | `[39,4.5,22]` | `[16,3.7,-4]` | 55° |

曝光 1、ACES 色调映射；原有太阳 2.65、环境强度 0.4、半球光 0.38、两个点光源 16 保持。新增 R1 窗口天空近似：标准聚光灯 `[11.35,2.4,-6.1]` 指向 `[6.6,0.4,-4.5]`，26cd、范围 8m、外锥角 0.86rad、penumbra 0.95；局部 PCF 阴影 1024²、normalBias 1mm。它是实时近似，周边可以有弱溢光，不是已算出的漫反射间接光或新烘焙。

`assets/wenku-library.glb` 为完整近景编辑模型，含标准 KHR_lights_punctual 局部灯及内嵌材质。`assets/tree-623-far.glb` 仍为远景单树编辑备选；Blender 内的远景备选集合默认隐藏，不与近景叠加。原有四台检查相机保留。

模型 UV0 用于现有重复纹理，部分超出 0—1 并有重叠，**没有可直接使用的独立不重叠 lightmap UV**。如果下一阶段安排局部烘焙，请以当前 GLB／Blender、上述灯光和相机为输入，由总策划安排展 UV、材质核对和局部烘焙；不能套用旧教室光照图。本轮没有执行烘焙，也没有新增生图需求。
