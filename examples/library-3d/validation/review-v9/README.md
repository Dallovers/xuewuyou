# 默认隐藏标记、随机抽书与阅读书签

本轮在 PR #52 的 `a635136255a9d5d5ab3ad1e0a9a1e3ef40b15b70` 上继续完善 C 图书馆，独立分支 `feature/c-library-reading-shelf`。PR 以尚未合并的 #52 分支为目标，只展示本轮增量；不合并或部署。

## 直接体验

本机实际后端入口：<http://127.0.0.1:5297/examples/library-3d/?view=sample>，预览入口为 5296。重新启动可在仓库根目录执行 `node examples/library-3d/server.mjs`，默认端口 4196。主站资料入口、返回路径和原有漫游继续可用。

1. 初次打开和刷新时，场景文字标记与金色提示圈均隐藏。需要指引时点击“互动标记：关”开启；也可用“探索清单”选目标，走近按 E。操作提示只在走近时出现。
2. 打开桌上导读书，点击“随机抽一本”，再点击“打开阅读”。抽取范围来自现有清单中可读取的本地 PDF／HTML，每轮不重复；不会新增虚构资料，打开时仍检查实际文件。
3. 在真实 PDF 阅读器翻页后点击“记住这一页”。关闭并刷新，再从“书签与摘记”点击“从第 N 页续读”。保存时正在渲染的页面不可操作；文件后来丢失时显示真实错误。页码超过文件长度会夹到最后一页。
4. 在阅读器点“写摘记”，或在书签条目展开摘记。填写后需点“保存摘记”；可导出 Markdown，包含当前未保存草稿。删除可撤销最近一条，同时恢复删除前草稿。横屏也保留三个紧凑互动入口。

## 保存范围与失败反馈

使用 `localStorage` 的 `xwy.library.public-shelf.v1`，最多 30 条书签、每条摘记 4000 字符，仅保存公开馆藏路径、页码、用户填写的摘记和更新时间。重复记页更新同一条目并保留摘记。HTML 资料保存为文本条目；Word 等下载文件、外站链接、失败的 PDF 和私有上传正文没有公共书签入口。

保存仅限当前浏览器和同一 origin；5296 与 5297、localhost 与 127.0.0.1 的记录各自独立。清除站点数据后会丢失，不跨账号或设备同步。本机公开摘记并非账号私有空间。刷新后未保存草稿及撤销状态不保留；导出的 Markdown 是备份，本轮没有导入功能。不会自动追踪后续翻页，需明确点击记页更新。

存储不可用／配额不足时在保存处显示失败，保留当前输入框草稿和旧数据；损坏 JSON 或不支持的版本不覆盖原数据。续读仅接受实际目录内的本地 PDF／HTML 路径；摘记以纯文本写入，不解释 HTML。保存前重新读取本机数据，避免删除后通过旧表单重新创建条目；多标签并发编辑仍按最后一次成功保存为准。

## 实现和所有权

- `src/interaction-guide.js` 只改变标记初始开关，保留原 16 个互动点、遮挡、距离约束和 E 键行为。
- `src/reading-activities.js` 从 `catalog.readableItems()` 抽取公开内容，复用现有 `catalog.read()`。没有独立上传或文档正文副本。
- `src/catalog.js` 在 PDF 实际渲染成功／HTML 正文读取成功后才开放记页与摘记，维护已渲染页码，并支持从保存页重新打开文件。
- `src/reading-shelf.js` 管理本机元数据、草稿和下载 Blob；定时释放下载 URL，dispose 解绑事件、清空草稿和撤销引用。嵌套弹窗保持场景暂停，关闭摘记后返回阅读器焦点；BFCache 保留同一场景。

没有调整几何、GLB／Blender、R1 UV1／atlas、灯光、服务端、A/B/D 或 #41 测试。原资产与 bundle 哈希见 [版本核验](version-audit.json)。本轮核对 main `7256f9274ff9269b903254acd0b7ed3a7bda1030`；相对先前核对的 `de7924e`，变更位于社交区、B 预览、相关文档和公共 Three.js 文件，C 图书馆实际输入没有新增差异。
