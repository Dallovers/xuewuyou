# 公共校园整合 · 一期

2026-10-23，本地分支 `integration/campus-hub-v1`。中央庭院、教学楼门厅与示范教室、完整图书馆、自习室、人物、社交广场和竞技场在同一个 Three.js 渲染器里。开门后直接走进房间，进屋自动转第一人称，出屋恢复第三人称；“回庭院”沿实际可走路线退出，不切换页面。

## 启动与入口

仓库根目录首次执行：

```powershell
npm ci --prefix server
node server/scripts/campus-preview-dev.cjs
```

打开 http://127.0.0.1:4184/js/features/campus-hub/index.html 。主站“今日校园”也增加了“进入 3D 校园庭院”。本地服务仅监听回环地址，使用 `server/data/campus-hub-preview` 隔离账号和学习数据，不连接线上账号库；不能直接双击 HTML 运行。

- “看总图”拖动旋转、滚轮缩放；“开始漫游”进入第三人称。
- WASD / 方向键移动，Shift 快跑，拖动转向，空格跳跃，E 进入或互动；手机提供方向、跳跃和进入按钮。
- 选择地点可沿碰撞允许的路线自动步行，手动移动取消路线。
- “地点 → 校园出口”可走到南侧步道的出口牌，按 E 退出 3D，回到原网站首页。右上角“返回网站”可直接返回，加载期间也能点击。只清除本标签页的校园返回票据，原登录与网站数据保持；离开页面沿原生命周期释放渲染器。
- 社交服务台与留言板复用原主站同伴功能；喷泉可开关，坐凳可用第一人称坐下环顾，E / Esc 起身。竞技场的锣和原业务入口保留。
- 打开业务面板暂停移动；关闭后回原站位，销毁 iframe 原文档；嵌套业务窗口优先处理 Esc。

庭院现在有八个实体互动点：流水控制柱、四张可坐下环顾的长椅、廊架桌上的导读书、教学楼前的校园导览牌和南侧网站出口。流水可开关；导读书打开原文库；导览面板选择地点后沿真实可走路线前往，支持键盘 Esc 和手机布局。坐下后停止移动，E / Esc 起身，保持原站位；打开面板时暂停人物与场景更新。

浅水池有独立底板、池壁、倒角分块压顶与落水涟漪；补齐齐平排水槽、廊架脚板/锚栓/梁/木百叶、座椅圆角分板和靠背、桌上书芯/封皮/书签、贴地花境。导览图是程序 Canvas，木作已接项目现有扫描 PBR，低灌木复用现有 A 的叶片资源；没有新增 AI 图片、外部模型或实时灯，也没有增加乔木。水景东侧保留四米通路；水池、座椅、廊柱、桌和牌有碰撞，廊架顶单独参与相机避让。

`src/courtyard.js` 集中庭院构建，重复构件按几何/材质/投影状态实例化；流水沿预建曲线更新 30 个水滴，限 20Hz，暂停/关闭后不更新，减少动态偏好下使用静态水滴。PC 水面已增加限频平面反射；仍没有流体模拟或全校园光照烘焙，不能视为整体照片级验收。庭院专项 `npm run test:courtyard`，最初细化实拍及报告见 `docs/team/visuals/campus-courtyard-v2/`。

## 写实渲染迭代（v3）

原建筑模型、朝向、业务入口和移动规则保留；改进扫描材质尺度/法线/粗糙度、浅水池建筑倒影、近景太阳阴影、HDR 天际线、树冠密度与人物接地阴影。石材使用原风化混凝土扫描的细节，经运行时低对比中性色重映射作维护良好的石材近似；灰砖按约 1m 纹理周期，橡木纹理沿板长投影。原图片未覆盖，来源和散列见 `docs/team/visuals/campus-photo-v3/`。

| 画质 | 水面 | 接触阴影 | 太阳阴影 |
| --- | --- | --- | --- |
| 自适应 PC | 384px 平面反射，近景最多 10Hz / 远景约 3Hz | 不启用 SSAO | 2048，漫游时缩小光空间包围范围 |
| 精细 PC | 768px 平面反射，同样限频 | 半分辨率、12 样本 SSAO；主颜色缓冲最多 4x MSAA | 4096，近景光空间范围 52m |
| 流畅 / 手机 | 原环境近似，关闭额外反射 | 不启用，释放后处理缓冲 | 2048 |

SSAO 不把透明叶卡、水面、天空和蒙皮人物当实心遮挡；人物依靠实际太阳投影和渐变接地影，避免轮廓光晕。切到轻路径后释放 compositor 及相关材质/噪声/渲染目标；pagehide 同时释放水反射目标、HDR 天空和原场景。减少动态偏好下停用水面相位动画，面板打开时冻结动态更新。远景三组体量是导航边界外的背景，无业务入口；延长地面和道路只为改善天际线，未扩张可行走边界。

构建与导航检查通过；v3 画质/资源/移动专项 8 项、庭院互动 15 项、校园往返 38 项、网站出口 6 项通过。截图均来自实际运行，尚未完成整校照片级验收；植被、远景外墙、建筑内部反射与整体 GI 仍有近似，原二次元人物形象按用户选择保留。精细模式有额外渲染成本，手机不启用这些效果；未把本机无头采样当作实体设备性能保证。

## 文件与重建

`src/app.js` 统一相机、输入、渲染循环和场景入口；`world.js` 组装共享地面和各板块；`navigation.js` 负责角色体积、分步碰撞及可达路线；`return-state.js` / `return-bridge.js` 负责入口往返；`business.js` 复用主站业务。新宿主可不安装 Blender。

```powershell
npm ci --prefix js/features/campus-hub
npm run build --prefix js/features/campus-hub
# 仅在原建筑模型变化时重提取、优化外壳：
npm run shells --prefix js/features/campus-hub
```

构建同时生成公共宿主和图书馆二维阅读面板，并按宿主 bundle / CSS 内容更新 HTML 缓存版本。共享宿主中的 Three.js 为 r170；社交独立页仍使用 r160，已把同版本核心与 RGBELoader 留在本地，避免运行时 CDN 依赖。原教学楼源码的 `@dgreenheck/ez-tree` 构建依赖固定为 1.1.0，MIT 许可见 `licenses/EZ-TREE-LICENSE.txt`；本宿主不创建其独立场地树木。模型、动作、PBR 和 A 植被素材来源不变。
