# 3D 校园、玩家与业务契约（待实现）

以下用于 A/B/C 对齐，不表示现有站点已具备这些 API 或 3D 能力。C 先做单人角色与本地缓存；现有多人自习继续走原实时系统。地图多人同屏后续另排。

## 场景与资源

- C 建立统一坐标系、米制比例和 `worldVersion`。总图、高度、GLB 模型、碰撞/导航网格使用同一变换和版本，换模型后重建导航并回归。
- 场景清单至少有：出生点、安全回退点、八地点 ID、建筑门口、触发范围、可行走面、阻挡、桥与楼梯。桥面可以与桥下同一平面坐标但高度不同，不能只采二维高度图。
- 灰盒先定义真实地形与通行关系。既有海岛图片用作构图参考；路径可按可玩性调整，不从图片亮暗猜出可走区域。
- C 交付 GLB 模型与动画、贴图、导航数据、授权清单。默认只进入建筑对应功能页面，本轮不额外制作八栋楼的可探索室内。

## 人物与移动验收

1. WASD/方向键与手机摇杆控制方向，速度按时间计算，斜向不额外加速；帧率变化不改变移动速度。
2. 点击地面先投射到合法可行走面，求可达路径；不可达位置有提示，不跨海/悬崖/墙体直线穿越。
3. 手动移动与自动寻路都约束角色体积，处理高度、坡度、台阶与障碍；快速移动不穿过薄墙。
4. 桥面/桥下分层正确；上台阶和下坡脚不悬空；边缘不掉出世界。异常位置回安全点并说明。
5. 新输入可取消自动路径；停止时 idle，运动时 walk/run，转向与动画一致。
6. 输入框、弹层、白板、地图 HUD、拖动镜头和摇杆不误触点击寻路；失焦后不继续卡键行走。
7. 到门口才出现“进入”动作，用户确认后打开功能；功能列表仍可直接进入，不以步行阻碍学习。
8. 跳转学习页后释放或暂停地图输入/渲染，退出时清理监听器、计时器和 GPU 资源；反复进入不创建多份循环。

## A 提供的建议接口

最终字段由 A/C 在灰盒验收时固定，并记录实现版本。

| 建议能力 | 最小契约 |
|---|---|
| `GET /api/campus/state` | 当前用户八地点的真实学习/可用状态、更新时间；模型估计标明估计，无数据返回空状态 |
| `GET /api/world/progress` | 当前用户 `worldVersion`、`sceneId`、位置、朝向、版本、服务器更新时间；无存档返回 null |
| `PUT /api/world/progress` | 携带 `expectedVersion` 保存；服务器校验数字有限、边界、场景版本、用户归属和请求大小；冲突返回 409 |

A 校验基本边界，C 用导航网格二次验证可站立位置；换版后旧位置失效回安全出生点，保留学习记录。位置不用于判定答题/积分/自习时长。记录不公开给其他用户。

本地移动无需后端每帧参与。停留后节流保存、切场景/可见性改变时尝试保存；退出写入不保证成功，保留可恢复缓存并显示保存状态。缓存按账号和世界版本隔离，退出/换账号时清除可见状态；未登录允许本地体验并标明未云同步。

## 三方界面边界

- B 给地图容器与全局设计 token；C 实现地图内部 HUD、控件、错误/加载和功能列表回退。C 提供新增模块引用给 B。
- C 经已有 `StudyAppBridge.navTo` 等入口进入功能，不直接写学习记录或复制一套社交系统。
- A 提供状态适配层，避免 C 直接读取整个账号存储；接口等待/失败不妨碍用户使用功能列表。

## 性能和失败场景

阶段 1 由 C 登记一台实际笔记本、一台实际中档手机、浏览器、网络和画质档位。建议目标：桌面接近 60 FPS、登记手机稳定至少 30 FPS；以持续走完整条路线的记录验收，不能只截静止帧。若不达标，减少阴影、像素比、模型/贴图和绘制次数，并记录降级表现。

先给首个可操作灰盒设下载预算（建议压缩资源 10 MB 内），详细版在实测后定预算；首屏不预加载八栋全部高精度模型与所有题库。资源有缓存、加载进度与超时重试。测试 WebGL 不支持/上下文丢失/模型或导航加载失败；可切功能列表或已有 2D 地图继续学习。
