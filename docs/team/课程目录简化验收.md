# 课程目录简化

左侧“课程地图”改名为“课程目录”。课程和章节页使用原有题库的学科、分组和章节数据，直接显示列表，移除地图画布和图片页头。数学模块显示“查看章节”，英语和雅思保留原练习流程。章节列表常驻，题数、难度及作答形态筛选保留，章节入口支持 Enter 和空格键。

首页的 3D 校园封面及入口保留。

验证：

- server 的 check 通过：前端语法、DOM 引用和地点注册表一致性。
- course-directory.cjs：13 项通过，覆盖三学科、筛选、键盘启动实际练习、390px 布局及浏览器错误。
- home-entry.cjs：11 项通过，覆盖首页封面、3D 实际进入/返回、手机布局、业务 iframe 和 Pages 子路径。
- 实际截图及记录位于 visuals/course-directory-v1。

在 js/features/campus-hub 目录运行：node tests/course-directory.cjs。可通过 CAMPUS_HUB_URL 指定验收网址；HTTPS 验收使用本机 7897 代理。测试仅注入浏览器本地学习档案，不登录或写入云端业务数据。
