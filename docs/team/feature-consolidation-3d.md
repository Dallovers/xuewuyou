# 功能合并后的 3D 校园地点规划

本文记录 2026-10-18 的入口收敛与后续功能建议。3D 主站接入、模型、导航网格仍按 [3D 契约](world-3d-contract.md)推进；当前 `world3d-demo.html` 是独立灰盒演示。

## 主站入口与地点

主导航保留五项：今日校园、课程与资料、错题与复习、自习室、同伴。地图地点仍保留八个稳定 ID，供 `/api/campus/state`、未来建筑门口和位置存档使用。地图可以为同一板块提供不同的具体任务，不要求一个地点对应一个独立页面。

合并仅调整入口层级，原有功能必须继续可达。首页的「全部功能入口」列出原入口名称；板块内通过二级导航切换。不要用资料问答替代通用 AI 助手，两者能力不同。

| 原功能 | 合并后的入口 |
| --- | --- |
| 校园地图 | 今日校园 |
| 课程地图 / 核心题库 | 课程与资料 → 课程地图 / 题库 |
| 随机组卷 | 今日校园 → 全部功能入口 → 随机组卷；地图随机训练场 |
| 学习资料 | 课程与资料 → 学习资料 |
| 课程问答 / 上传资料 | 课程与资料 → 课程问答 |

| 拍照搜题 / 自由提问 | 右下角 AI 助手；AI 助手页 → 自由提问 / 拍照搜题 |
| 错题本 / 重刷 / 变式训练 | 错题与复习 → 错题本，保留题目原有操作 |

| 题目白板 / 已存草稿 | 练习题目或挑战复盘 → 题目白板，按题号重新打开 |

AI 讲题和出题使用用户输入；备考计划支持设置考试天数；个性化计划读取当前账号的待攻克错题。空记录时提示先练习或手动填写知识点。首页重复的宣传卡片与没有实际功能的「敬请期待」卡片不属于独立功能。

## 适合在 3D 校园逐步增加的活动

1. **模拟考场，优先级最高。** 在随机训练场升级：固定题量和时长、交卷后展示题目级复盘，错题进入现有复习流。需要单独记录模拟场次，不能把现有无限量随机练习称作模拟考试。
2. **任务公告板，优先级第二。** 放在校园公共空间：显示今天到期的复习、上次未完成的练习、一个薄弱章节。任务来自现有真实记录；点击后直达功能页，完成状态由作答或复习结果回写。它适合作为 3D 场景交互点，无需新增建筑或一级页面。
3. **成果展廊，优先级第三。** 靠近成长中心：展示可核对的阶段成果，例如已完成章节、复习次数、个人自习记录和保存的草稿。先做仅本人可见，再决定是否开放分享。

先验收建筑入口、步行、手机操作与 2D 回退，再扩建活动。新增建筑时为其定义稳定 ID、真实行为、空状态与服务端状态来源，并同步更新前端注册表、3D 场景和 `/api/campus/state`。
