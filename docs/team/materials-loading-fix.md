# 学习资料目录加载修复

2026-10-24：用户反馈资料一直加载，列表不出现。

## 修复

- 主站资料页改用 WG_Heavy.readyWenku，只加载资料数据与分类引擎，不再等待 3.7 MB 题库及词库。浏览器脚本使用异步执行，避免独立请求仍被 async=false 的题库阻塞。
- 与后台共享进行中的请求，重复点击不重复下载；单文件请求 15 秒超时，失败移除请求缓存，提供「重新加载资料」。失败不再退回首页或显示永久空目录。
- 分类引擎会缓存初始化时的资料列表，因此原始资料下载失败时不能继续初始化分类。重试先恢复原始数据，再初始化分类。
- 用户在加载期间切去首页，下载完成后不强行跳回资料页。校园内嵌的主站资料页也不再先等整批题库。
- 3D 图书馆的可选文件清单等待上限 5 秒，失败仍开放目录；打开文件时独立验证实际文件。同步重建独立图书馆与校园 2D 阅读面板，并更新缓存版本。

## 验证

- node --test server/test/materials-loader.test.js：独立加载、请求去重、失败重试、超时。
- CAMPUS_TEST_BASE=http://127.0.0.1:4198/ node js/features/campus-hub/tests/materials.cjs：人为卡住题库仍能打开资料、搜索、下载失败后的重试、导航期间异步完成、图书馆清单卡住仍开放目录与真实 PDF 渲染。
- 浏览器测试需先启动本地静态 / Node 服务；测试不登录生产账号，不写生产资料或学习记录。
- 本次只修改前端及测试，不需要重建华为云 API，也不改变数据库和账号。Pages 更新后刷新主站与已打开的校园页。
