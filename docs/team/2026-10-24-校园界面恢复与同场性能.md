# 校园界面恢复与同场性能

## 已确认的问题

PR #98 合并后的 main `a8e38e3` 保留了竞技场的新站位与 NPC，但同时将 PR #96 的普通按钮样式和 PR #97 的校园工具栏、深色面板、手机排布、自习室旋转碰撞修复覆盖回了旧版。GitHub Pages 的实际 HTML 已确认出现旧版按钮和 CSS 版本号；这不是仅靠刷新就能修复的浏览器缓存问题。

本轮恢复公共界面与导航修复，保留竞技场站位、NPC、对答手势及台阶平滑升降。切换到总览也会释放作答站位，避免恢复漫游后不能移动。

## 性能与连接

- 自动画质漫游改用环境光照水面，避免周期性额外绘制整座校园的平面倒影；总览仍保留倒影，显式选择“精细”时保留完整倒影与 AO。
- 同类人物共享下载的原始文件，每个人仍分别解析和持有骨骼、材质与动作，避免离场释放资源伤及其他角色。
- VRM 使用官方 combineSkeletons 合并兼容骨架，减少重复骨骼计算，保留当前形象与动作。
- 同学角色在首次显示前异步预编译材质；动态角色保留脚下接触阴影，不再因其他玩家移动而不断重绘整座校园的阴影。
- 角色文件临时加载失败会自动退避重试，失败下载不会留在成功缓存中；“重新连接”在已加入时也能真正重新建立连接。

用户随后确认互相可见已恢复，本轮没有将单向可见归因于未经证实的服务器故障。线上握手正常不等于线上所有用户网络稳定，也不等于已完成两位用户设备的性能验收。

## 验证入口

在 `js/features/campus-hub` 安装依赖并构建后运行：

```powershell
npm run build
node tests/navigation.mjs
node tests/controls-layout.cjs
node tests/presence.cjs
node tests/input.cjs
node tests/interiors.cjs
node tests/visual-quality.cjs
node tests/recovery.cjs
```

浏览器测试需要本地隔离后端 `http://127.0.0.1:4184`。同场测试会创建本地验收账号，禁止指向生产环境。presence 测试包含主动制造一次远程模型 503、自动恢复，以及重新加入时不重复下载的验证。

服务器目录运行 `npm run check` 和 `node --test test/campus-ui.test.js test/campus-presence.test.js`。新增公共界面守护检查进入现有服务端 CI，覆盖必需控制入口、生成文件的缓存哈希、普通按钮不恢复贴图效果。

本机截图与结果在 `js/features/campus-hub/test-results/controls-layout`、`presence-v8`、`campus-recovery`。本机 Chromium 样本不能代替真实手机帧率。
