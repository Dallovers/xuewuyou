# B · 全站界面与体验改进计划

日期：2026-10-17　范围：`index.html`、全站 CSS、`js/ux.js`、`js/campus-interactions.js`、品牌与字体
基线：`main`（线上题库 `js/gaoshu_bank.js` 1823 题 / 25 主题；`data/gaoshu_bank.json` 是 850 题的旧快照，不参与线上渲染）

---

## 一、结论先行

1. 用户说的「乱码」不是字体或编码问题，是**抓取残留 + 渲染降级**两件事叠在一起：
   公式被自研的 LaTeX→纯文本转换器压成了 `√() 3`、`\ β<0` 这种半成品，
   正文里还有没清掉的 HTML 标签和被删掉 `\begin` 的表格残片。
   **线上 1823 题里 529 题（29%）能看到这类缺陷。**
2. 视觉层其实有底子：`:root` 已有颜色/间距/圆角 token，对比度也标注过，`prefers-reduced-motion` 覆盖了 7 处。
   问题不在「不好看」，在**没人守规矩**：80 个硬编码色值、42 个 `!important`、123 处内联样式、
   `atlas.css` 被压成 66 行超长单行。所以这轮是**收敛 + 补状态**，不是重做视觉。
3. 所以顺序必须是：**先让人读得懂题 → 再让页面有状态 → 再谈每页的版式差异 → 最后收设计系统**。
   反过来做（先美化）等于在乱码外面镀金。

> 2026-10-17 更新：第 1 步已落地并实测，线上题库缺陷 **529 → 0**，KaTeX 渲染成功率 **99.8%**。
> 实施明细见文末「九、实施记录」。

## 三、改进原则（B 的取舍）

- **不动业务逻辑**。`js/app.js`、`js/gaoshu.js`、题库数据归 A。B 只新增渲染/样式层，并给 A 明确的调用点补丁。
- **先可读，再好看**。题面、解析、表单的清晰度优先于首页的视觉冲击。
- **一页一主任务**。首页答「现在该做什么」，练习页答「这题怎么想」，报告页答「我差在哪」。
- **保留视觉签名**：格纹作业纸底、胶囊按钮 + 方角卡片、左侧 3px 薄荷书脊。这是识别度，不推翻。
- **不加框架**。不引入 Tailwind/组件库，不换字体家族；用现有 token 收敛。
- **不做的**：暗色模式、3D 场景内 UI（C 负责）、学习工作台（已下线不恢复）。

## 四、四步计划

### 第 1 步｜题面可读性抢救（最高优先，先做这个）

**做什么**

1. 新增 `js/mathview.js`（B 自有新文件，不改 A 的文件）：
   - `WG_Math.render(el, tex)`：把原始 LaTeX 交给已内置的 KaTeX 渲染，`throwOnError: false`；
   - 渲染前过一道 `sanitize()`：截断 `\d+:\["\$","\$L\d+"` 起的源码残留、剥掉 HTML 标签、修 `\sqrt X` → `\sqrt{X}`；
   - 失败回退：KaTeX 报错时退回现有 `latexToText()` 结果，并给元素打 `data-tex-fallback` 便于统计；
   - 可视区优先渲染（IntersectionObserver），避免 850 题里的长解析一次性排版卡顿。
2. 题干/选项/解析统一走 `WG_Math`：题干 17px / 行高 1.9 / 最大行宽 68ch；公式块 `display` 模式居中、上下 12px；
   手机端公式块横向滚动而非折行。
3. 选项改整行卡片：字母键固定左侧圆形，文字垂直居中，点击区 ≥ 44px；判分后只保留对/错配色。
4. 解析改「结论先行」：顶部一行答案 chip（正确项/最终答案/掌握度），下面才是步骤；`sol-step` 折叠保留。

**交付**：`js/mathview.js`、`css/question.css`、给 A 的两处调用点补丁（`gaoshu.js` 的 `render()` 与 `solHtml()`）。

**验收**：审计脚本 0 残留；随机抽 50 题逐题对照，`√()`、反斜杠、JSON 尾串均不再出现；公式块在 390px 下不撑破页面。

**给 A 的两张单（B 不直接改）**

- 数据清洗：`solution` 尾部从 `\d+:\["\$","\$L\d+"` 起截断；`\sqrt` 无花括号补 `{}`；清 HTML 标签。附清洗前后计数。
- 调用点替换：把 `esc(latexToText(x))` 换成 `WG_Math.mount(node, x)`，共 3 处（题干、选项、解析块）。

---

### 第 2 步｜状态体系（一页五态）

**做什么**：在 `js/ux.js` 落一个统一 `WG_UX.state(container, {kind, title, desc, action})`，配 `css/states.css`：

| 状态 | 用在哪 | 具体要求 |
|---|---|---|
| `loading` | 所有接口页 | 骨架屏延续真实版式（不是转圈），>800ms 才显示，避免闪 |
| `waking` | 免费后端休眠 | 明确「服务正在唤醒，约 60 秒」，带秒数倒计时 + 自动重试，可离开 |
| `empty` | 错题本/资料/留言/自习 | 说明「为什么空」+ 一个下一步动作，禁用「暂无数据」四个字了事 |
| `error` | 网络/判分/上传 | 保留用户已输入内容，给「重试」；错误码可折叠 |
| `locked` | 未配置 RAGFlow/MinerU/模型 | 显示「未配置」而不是假装能答，附配置入口 |
| `submitting` | 提交答案/发留言/上传 | 按钮原地 loading + 禁双击 + 成功/失败就地反馈 |

**验收**：每个视图用 `?demo=empty|error|waking` 走一遍（需 A 加开关）；断网 10 秒下不留白屏。

### 第 3 步｜页面差异化与信息架构

| 页面 | 现在 | 改成 |
|---|---|---|
| 首页 | 8 分区入口 + 数据卡片 | 三段落：「继续上次」（一步回到断点）、「今天要复习 N 题」（到期队列）、「薄弱章节」；地图入口保留但不做主角 |
| 课程/章节 | 地图节点 + 列表 | 保留；节点补「已掌握/待复习」两态图例，颜色只用语义色 |
| 练习 | 题干 + 选项 + 解析 | 第 1 步的阅读规格；顶部进度条 + 标记 + 白板入口收成一条工具条 |
| 错题本 | 列表 | 按「错因/章节/时间」分组视图 + 批量重做，而不是无限长列表 |
| 学情报告 | 若干统计卡 | 结论句开头（「你的薄弱点是假设检验」）+ 趋势 + 下钻，避免数字堆砌 |
| 自习室 | 计时 + 成员 | 计时做主视觉（大号等宽数字），成员状态次之；全屏模式减少装饰 |
| 资料/问答 | 上传 + 列表 | 上传区与文档列表分区；引用片段用引用块样式，可回溯 |
| 校园互动 | 便签墙 | 保留墙面质感，正文/回复提高对比度；手机单列 |

**导航收敛**：12 项 → 5 个主入口（校园地图 / 课程 / 自习室 / 错题本 / 我的）＋「更多」分组放学情报告、智能复习、课程问答、校园互动、AI 助手。侧栏不改宽度，只改分组层级。

### 第 4 步｜设计系统收敛 + 响应式与可访问性

- **色值收敛**：80 个 hex → 保留现有 `:root` 语义色，页面里硬编码色替换为 `var(--*)`；新增 `--surface-3`、`--border-soft` 各一个即可，不再加新色。
- **去 `!important`**：42 处逐条定位来源（多为层叠顺序问题），用提高选择器特异度或调整文件引入顺序解决；`campus-theme.css`/`campus-adventure.css` 的覆盖关系画一张表再动。
- **内联样式迁移**：`index.html` 123 处 → 收进对应 CSS 类；`gaoshu.js` 里的 header 内联样式随第 1 步一起迁走（由 A 合入）。
- **拆 `atlas.css`**：66 行超长单行拆成常规格式，按「布局 / 导航 / 卡片 / 地图容器」分段，纯格式改动、无行为变化。
- **响应式**：320/375/390/768/1440 五档；主要触控区 ≥ 44px；`focus-visible` 已覆盖 26 处，补齐弹层与自定义控件。
- **可访问性**：`skip-link` 保留；弹层补焦点陷阱与 `Esc`；`aria-live` 播报判分结果；`prefers-reduced-motion` 覆盖新增动画。

## 五、与 A / C 的接口契约

**给 A（业务侧）**

- 渲染：`WG_Math.mount(el, rawLatex)`，A 只替换调用点，不改数据结构。
- 状态：`WG_UX.state(el, {kind, ...})`，A 在 catch/await 处调用，B 不碰请求逻辑。
- DOM 契约：题面容器 `.bank-q`、选项 `.bank-opt`、解析 `.bank-sol` 三个选择器保持稳定；B 改结构前先提 PR 说明。
- 演示开关：`?demo=empty|error|waking` 仅开发环境生效。

**给 C（3D 侧）**

- 地图 HUD、摇杆、加载/错误面板复用 B 的 token 与状态组件同构样式（C 自己实现文件，B 只做一致性检查）。
- 画布容器只吃 `--s*` 间距和 `--r*` 圆角，不引新色。

### 新增文件

- `js/mathview.js`　题面渲染层 `WG_Math`：清理抓取残留 → KaTeX 渲染 → 失败降级到纯文本。
  三个关键修正：
  1. `\n` 字面转义还原成换行（题库里两万余处，公式内外都有），同时白名单保护 `\nabla`、`\neq`、`\nu` 等真命令；
  2. `\sqrt 3` 补成 `\sqrt{3}`，消灭 `√()3`；
  3. 矩阵/分段函数只靠换行分行时补 `\\`；9 个元素无 `&` 的 3×3 行列式按行还原成 3 列；
  4. 裸 `\begin{array}` 表格自动当公式处理，不再被当残留命令删掉。
- `css/question.css`　题面排版：试卷纸卡片 + 左侧薄荷书脊、17px/1.95 题面、整行选项卡、

### 修改文件

- `js/gaoshu.js`（**仅 3 处调用点 + 1 处容器，需 A 复核**）：
  - `render()` 里题干、选项改用 `renderRich()`（`WG_Math.toHtml`，缺失时回退旧 `latexToText`）；
  - `solBlocks()` 改用 `WG_Math.plain()`，`blockHtml()` 用 `richText()` 展开公式占位符；
  - 题目外层包 `<article class="bank-card">`，顶部信息条改为 `.bank-head` 结构（样式全在 `question.css`）。
  - **未改动任何判分、选项目解析、掌握度、答题卡逻辑。**
- `index.html`：引入 `css/question.css`、`js/mathview.js`（`gaoshu.js` 之后加载，便于注册降级转换器）。
- `css/question.css` 里把答题页 `game-head` 从 120px 暗色海报收成一条工具条，题目重新成为视觉主体。
