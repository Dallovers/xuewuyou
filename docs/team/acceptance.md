# 联合验收清单

不是“页面能打开就完成”。A 提供自动化与发布证据，B、C 做交叉测试，你完成真实试用。发现的问题记录复现步骤、影响、负责人、修复提交与复测结果，已知可复现问题清零后发布。

## 关键流程

- [ ] 注册/登录、账号错误、首次等待、断网、退出和换账号都有正确反馈；不静默变为另一个数据模式。
- [ ] 刷新与服务重启后，账号数据、草稿、互动和自习历史仍存在。
- [ ] 当前账号不能读取、覆盖另一账号的资料、题目草稿、续学会话或私有房间。
- [ ] 做题→记录→错题/复习→报告一致；重复点击、重试与恢复不重复统计。
- [ ] 断点续学保留顺序、当前位置和草稿；换设备可继续；版本冲突不静默覆盖。
- [ ] 白板能画、保存、重新打开和导出；长题目/公式不挤坏工具区。
- [ ] 两个独立账号完成好友确认、留言回复和五题挑战；判分、权限与复盘正确。
- [ ] 两人自习能准备、开始、同步、暂停、休息、重连、房主转移与结束；后台/多标签不重复累计。
- [ ] TXT/MD 上传、解析、读取、删除可完成；模型、检索、PDF/Office 解析按真实服务状态展示。
- [ ] 所有可点入口均能完成所宣称的动作；未配置能力如实说明，不用模拟在线人数/成绩/回答冒充结果。

## 界面与地图

- [ ] 登录、首页、课程/章节、练习、自习、资料、错题、报告、复习、问答、社交、AI和主要弹层均验收。
- [ ] 320/375/390/768/1440 宽度测试；检查真实控件是否超出视口，不只看是否隐藏了横向滚动。
- [ ] 键盘可操作，焦点可见；长昵称、长留言、公式、加载/空/错/禁用状态不破版。
- [ ] 文字清晰、图标统一、装饰不过度干扰内容；没有整页通用口号、假成功或重复横幅掩盖空白。
- [ ] 八个地图地点的名称、建筑、入口和状态对应正确；手机有可理解的名称/列表回退。
- [ ] 学院、自习馆使用不同建筑；素材透明、落地、比例一致，失败时仍可进入功能。
- [ ] 图片里不写死动态数据；学习状态来自记录，模型估计有明确说明。
- [ ] 不恢复已删除的学习工作台，不重复创建另一套朋友、留言或房间系统。

## 测试与发布

- [ ] `npm run check` 与后端测试通过；数据库专项实际执行，不能用“跳过”代替通过。
- [ ] 浏览器自动化覆盖双账号、刷新、断网恢复、账号切换、关键提交及移动端。
- [ ] 控制台无未处理异常；无缺失脚本/字体/图片；关键 API 失败有状态和恢复入口。
- [ ] GitHub 代码、Pages 前端与 Render 后端使用预期版本；实际跨域、鉴权和 Socket.IO 公网验证通过。
- [ ] 发布后从未登录设备与已登录设备各试一次；测试账号/测试内容清理；保留回滚版本和步骤。
- [ ] 你按“进入地图→继续练习→写草稿→复习→看报告→与队友自习”的路径完整试用。
