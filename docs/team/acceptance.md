# 联合验收清单

按已知可复现问题清零、关键自动化通过、上线复查验收；记录问题复现、负责人、修复提交和复测。A 汇总发布证据，B/C 验证各自模块并交叉测试，你真实试用。

## A：业务与数据

- [ ] 登录等待、账号错误、断网、退出/换账号反馈正确，不静默切换数据模式。
- [ ] 刷新与服务重启后，学习/草稿/互动/自习数据保留；不同账号不能读取或覆盖私有记录。
- [ ] 答题、错题、复习、报告一致；重试、重复提交和恢复不重复计分。
- [ ] 续学保留题序/位置/草稿；第二设备可继续；409 冲突和题目失效能恢复，不默默清空。
- [ ] 白板可画、保存、重开、导出；两账号好友/留言/竞技与权限校验通过。
- [ ] 双账号自习的准备、开始、暂停、重连、房主转移、结束和服务重启通过；多标签不重复计时。
- [ ] TXT/MD 流程正常；模型/检索/解析等服务如实显示可用或待配置，不用模拟结果冒充真实。
- [ ] 题库旧 ID 兼容、复用/独立题口径清楚、7 条字段异常完成核查；导入可校验/隔离/回滚。
- [ ] 新题满足[内容计划](question-bank-plan.md)阶段目标，题型/难度/章节覆盖、来源、答案/解析和审校记录齐全；模板变式单列，不虚增题数。
- [ ] 题库按需分发/组卷，不因扩容卡死手机；换版不破坏旧错题、续学、草稿或挑战复盘。

## B：全站界面

- [ ] 登录、首页、课程/章节、练习、自习、资料、错题、报告、复习、问答、社交、AI 及主要弹层覆盖。
- [ ] 320/375/390/768/1440 宽度；长公式、题目、昵称、留言可读，不靠隐藏溢出掩盖破版。
- [ ] 键盘可操作、焦点可见；加载/空/错/禁用/未配置/提交中均可理解并能恢复。
- [ ] 页面布局适合各自任务，字体/图标统一；没有假在线人数、假成果、堆叠通用口号与重复横幅。

## C：真实 3D 与角色

- [ ] 场景与角色使用真实 3D 模型，可观察深度/遮挡/镜头变化；平面底图人物贴片不算完成。
- [ ] 键盘、点击寻路、手机摇杆可用；斜向速度一致，帧率不同速度不变；走/跑/停动画匹配。
- [ ] 地面、坡、阶梯、桥面/桥下高度正确；不穿墙、不踩海、不从断崖越界、不悬空或钻地。
- [ ] 不可达目标有提示；新指令能取消旧路径；转角/薄墙/高速操作不穿障碍，异常位置可安全恢复。
- [ ] 输入/白板/弹层/HUD/拖相机不触发行走，失焦不会卡键；开功能页暂停地图操作与渲染。
- [ ] 八地点均可达、入口功能正确；学院和自习馆独立；功能列表可直接进入且资源失败可用。
- [ ] 位置存档按用户/版本隔离，非法位置恢复安全点；学习状态来自 A，不因走到建筑自动加分。
- [ ] GLB/纹理/动画/导航的版本、来源清楚；在登记笔记本/手机上走完整路线，帧率/内存/加载证据达阶段预算。
- [ ] WebGL/资源/导航失败有可用回退；反复进出地图无重复监听/渲染循环或持续内存增长。

## 发布与整体试用

- [ ] 后端检查、测试与真实 PostgreSQL 专项通过；跳过不算通过。浏览器覆盖双账号、刷新、断网、移动端、关键提交。
- [ ] 控制台无未处理异常、无缺失脚本/模型/字体/图片；公网跨域、鉴权、Socket.IO 通过。
- [ ] GitHub/Pages/Render 版本有记录，迁移与资源发布顺序正确，测试数据清理，保留回滚步骤。
- [ ] 不恢复已删除工作台；本轮不把单人 3D 地图称为地图多人同屏，也不把概念图称为实体校园数字孪生。
- [ ] 你按“登录→移动到学院→做题→写草稿→刷新续学→复习→看报告→去营地与队友自习”完整试用；列表直达也可完成学习。
