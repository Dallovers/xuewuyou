# 今日校园首页改为3D开放校园入口

2026-10-23。在整合分支 `cffa594` 上创建 `feature/home-campus-entry`，先合入线上 main `3b2756023e6e5819c5e02fb33acd883ee365d539`，保留地点注册表一致性检查及竞技场更新；竞技牌面冲突保留已实测的朝庭院方向修复。

## 页面变化

旧首页校园探索地图替换为大幅AI生成的现代中国校园封面，主标题“走进你的3D开放校园”，整张封面可点击或用键盘进入 `js/features/campus-hub/index.html`。手机首屏保留入口。封面下有课程、资料、自习和搭子快捷入口，再显示原学习足迹和完整功能目录。

封面通过内置 image_gen 生成，提示词及源文件在 `vendor/campus-home/README.md`。页面诚实标注为概念封面，运行时仍用真实3D几何。桌面WebP约254KiB，手机约79KiB；首页不初始化3D，不再创建原校园Phaser地图；课程与章节地图仍使用原引擎。嵌入的原账号/业务页面隐藏封面及递归3D入口。

`index.html` 为可访问语义与页面结构；`css/campus-home.css` 仅作用于新首页组件；`js/atlas.js` 首页路径只渲染原统计/建议/同步状态，课程与章节绘图保持。`js/campus-hub-entry.js` 继续阻止 iframe 递归打开3D。新样式、原地图样式、atlas脚本和嵌入脚本版本均更新。

## 验收

`validation.json`：11项通过，覆盖新入口/旧地图移除、不预载角色或地图引擎、学习记录保留、课程地图保留、真实键盘进入共享3D、返回网站、390px布局与移动封面、业务 iframe、代理模拟 `/xuewuyou/` Pages 项目路径、浏览器错误和素材加载。

`npm run check --prefix server` 通过：前端语法35文件、引用419个ID、注册表8个地点一致。截图 `desktop.png` 与 `mobile.png` 均来自本地实际网页。Windows使用单CPU亲和性的Node22.14.0运行浏览器测试，没有把无头浏览器验证视为实体手机性能测试。

本改动包含完整共享校园，线上需前后端版本同步才能提供多人同场。没有在首页增加假在线人数，也未将概念封面描述为照片级运行效果。
