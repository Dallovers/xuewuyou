# B 屋顶更新：本地复核与校园接入

2026-10-23，来源 [PR #88](https://github.com/Dallovers/xuewuyou/pull/88)，精确提交 `382c5832dc924f02cb89d3474c6d481a058b169e`。审查时 PR 为 open、未合并；本地 cherry-pick 到 `integration/campus-hub-v1`，不执行远端合并、推送或部署。

## 已核对的变化

- 原平顶改成四坡蓝灰金属屋面，屋面 13.58 × 10.58 m，檐高 3.86 m，起坡 0.80408 m；原净室内 12 × 9 m、门洞和入口位置不变。
- 门口不再被旧 `maxZ=4.44` 边界钳住。B 单页边界扩大到室外；公共校园继续使用宿主自己的导航范围，未把 B 的大范围当建筑占地。
- 6 盆植物，其中 4 个落地盆参与碰撞；新增乘性遮蔽层是程序近似，不能作为真实 GI 烘焙验收。
- B 的 `createOutdoor` 仅在原自习室预览调用。校园宿主不调用它，避免重复地坪、天空、雾和树林覆盖公共场地。

## 本地补齐

1. 原 `createRoof` 仅给南北梯形坡生成锁边，两端三角坡缺少锁边，与 PR 描述的四坡连续板缝不一致。补充两端顺坡、截到斜脊的实例：南北各 23、东西各 18，共 82 道，仍合为一个 InstancedMesh。
2. 公共宿主原相机包络按旧平顶 4.2 m 设置。新包络取实际屋面、封檐、脊与锁边几何的世界包围盒；雨水管不拉低屋面包络。出檐只用于相机阻挡，不扩张行人导航障碍。
3. 更新 B 的模块依赖和预览脚本版本，避免服务端一天静态缓存造成新旧材料/房间/碰撞混用；保留“返回校园”桥接。
4. 校园回归的 iframe 检查原来只等待房间区可见，此时最后一个 defer 脚本可能尚未执行。改为等待宿主真正完成 iframe load 握手后再断言 3D 入口隐藏，保留全部原断言。

当前仍有明显原型感：自习室东/南外墙较空，独立预览的地坪和树线是占位环境；屋顶更新本身不代表整体已达到照片级。
