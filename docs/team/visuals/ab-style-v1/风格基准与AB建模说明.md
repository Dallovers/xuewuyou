## A：好友社交广场

第一批按“亭廊 + 公告栏 + 服务台 + 坐凳 + 喷泉 + 通路”拆分，作为自己的社交板块真实 3D 模块。建筑背景可先复用公共立面，不要求 A 独立重建整栋教学楼。

| 构件 | 参考用途 | 对应业务/交互 |
|---|---|---|
| 开放亭廊和服务台 | 社交板块主要识别点 | 打开真实搭子列表和好友申请 |
| 深青铜框公告栏 | 独立可替换展板，不把文字烘进墙体贴图 | 校园留言、查看与发布 |
| 小型浅水喷泉 | 场景互动设施，单独管理水面和喷嘴 | 开关水流；不与好友业务完成状态混淆 |
| 石座和木坐面 | 提供停留位置 | 坐下/退出，或首批仅保持通行友好 |
| 公共主路 | 连接其他校园板块 | 角色行走、明确入口 |

拟定尺寸起点：场地区域约 22×18 m，主通路约 4.5 m；亭廊长约 7 m、高约 3.2 m；喷泉直径约 4 m、池边约 0.4 m 高；座椅坐面约 0.45 m 高。这些是建模约定，不能当作图片已准确表达的施工尺寸。交付前由统一总图校核入口、坡道、台阶与通行范围。

优先做柱梁厚度、屋檐收口、板框和坐凳连接；细水花、落叶、微小污迹不作为首轮建模任务。喷泉水流效果由统一渲染实现，几何结构保持独立。

## B：自习室

第一批按“墙地顶/门窗 + 标准桌椅 + 窗边席 + 低书架 + 入口控制点”拆分。保持入口与主走道清楚，桌椅不要堵住门扇或互相穿插。

| 构件 | 参考用途 | 对应业务/交互 |
|---|---|---|
| 双向或组合学习桌 | 可重复模块，适量排列 | 选位与开始个人专注 |
| 灰绿软包椅 | 同一规格，真实支撑与地面接触 | 坐下/退出反馈 |
| 窗边长桌与高凳 | 形成与桌岛不同的学习位置 | 自习位，不强制新增另一套业务 |
| 入口墙面控制点 | 保留外壳与业务显示区域的分离 | 房间列表、加入、准备与共同计时 |
| 低书架与钟表 | 空间识别和状态呈现位置 | 计时状态从真实业务读取；物理钟可先作静态道具 |

拟定尺寸起点：房间约 12×9 m、净高约 3.8 m；主走道约 1.5 m；普通桌高约 0.74 m，普通椅坐面约 0.45 m；窗边高桌与高凳另按一组匹配尺寸制作，不直接沿用普通座椅高度。现场座席数量依据通行和实际占地调整，不要求机械复刻图片里被遮挡或数量不清的家具。

优先保证桌板厚度、椅腿/靠背连接、门框与玻璃厚度、清楚的地面和墙面分区。笔记本、杯子等装饰只放少量，可后补。多人占位和计时若要同步，必须接真实服务端状态，生图中的座位不代表已实现联机。

## 怎样用这两张图防止质量偏差

1. 三个人共用同一套材质和已验收构件；允许空间体量与布局不同。
2. A 先交亭廊一个柱梁转角、公告栏和一张坐凳；B 先交一组桌椅和一段门窗。用这些代表样件对照图片检查结构。
3. 在你主机同一预览环境检查尺寸、结构、材质，再扩展到完整区域；队友电脑可关闭高成本预览效果。
4. 新增构件需要补参考时，由我继续生成局部、多角度或材质示意。多张 AI 图可能存在尺寸/结构差异，最终以验收后的源模型和尺寸约定为准。
5. 这组图作为第一版风格基准。先制作小样再确定完整资产库，避免把图中的所有装饰一次做满。
