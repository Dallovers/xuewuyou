# 3D 校园操作界面

采用深色半透明工具栏、低饱和绿色操作按钮和少量暖金色提示。全部为真实 HTML/CSS 控件，不使用图片按钮。

- 顶部：总览/漫游切换、校园地点、操作指南、返回网站。两个视角使用真实 aria-pressed 状态。
- 地点：默认收起，打开后可关闭或按 Esc 返回，选择目的地自动收起并沿原路线行走。
- 底部：当前位置、主要互动及画质选择；尺寸随标题和屏幕变化测量，移动键和工具条随底部高度避让。
- 手机：方向键在左、跳跃在右；入座和弹窗时收起移动键，拿书/入座工具按状态出现。提示消息移到上方，避免盖住操作。
- 弹窗：深色标题栏、分层内容与背景虚化；增加操作指南，设备分为预设/单独控制，课程选项和笔记操作分组。原资料阅读与主站业务继续使用原界面。

## “回庭院”修复

此前 #92 将自习室转向 119.15°，worldBoxes 却把旋转墙体/家具的包围盒当成实际碰撞范围，导致房内通道被虚假扩大、寻路失败。现在保留世界包围盒供相机及粗筛使用，非直角建筑再按局部旋转坐标精确检查脚印；角色半径和移动切片保留。

导航测试增加斜墙旁通道和高速防穿墙。室内测试修正旧的进门朝向（旧 -1.062 会朝门外行走），以实际进入室内作为判据；拿书和座位候选使用实际可走站位，保留拾取、翻书、放回、入座和实际走回庭院的完整断言。
