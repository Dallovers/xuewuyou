# 中央庭院：水景、阅读廊架与七处互动

2026-10-23，基于本地 `eecdb8c`，仍在 `integration/campus-hub-v1`；未推送、远端合并或部署。

设计将原来大片同质铺装分成中央浅水景、西侧阅读廊架和低矮花境。保留原八棵乔木。配色沿用灰米石材、蓝灰水面、深青铜构件、橡木色木作及灰绿植被，不改变原建筑体量与朝庭院的自习室入口。

- 水景：独立池底/池壁、分块倒角压顶、贴地石材边带、齐平排水槽和三道低弧循环水；控制柱按 E 切换。
- 阅读廊架：石础、脚板、锚栓、柱、承重梁与木百叶；两张带靠背的长椅可坐下环顾；桌上导读书打开原 `wenku` 页面。
- 水边：两张分板木长椅，E 坐下，E / Esc 起身，坐下不随移动键滑动。
- 校园导览牌：实体搪瓷示意图。按 E 打开五处目的地，选择后实际沿碰撞允许路线行走；同时提示庭院新互动。
- 细节：木材程序纹理、书芯/封皮/书签、灌木叶丛与观赏草、压顶拼缝、排水槽横条。水景东侧留约四米通路。

重复件按几何/材质/投影状态实例化。新增流水只更新 30 个实例水滴，20Hz 上限，关闭/暂停时不更新；减少动态偏好下水滴保持静止。几何与程序贴图按原宿主生命周期释放，廊架顶另设相机阻挡。没有新 RAF、实时灯、远程运行依赖或 AI 生成图片；低灌木复用既有 A 叶片贴图，来源沿原素材说明。水面、程序木纹、植被与环境反射仍为实时近似，没有新增光照烘焙或真实流体。
