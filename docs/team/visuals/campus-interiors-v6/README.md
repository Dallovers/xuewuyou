# 同一校园连续室内与业务接入 v6

日期：2026-10-23。基于本地 `integration/campus-hub-v1` 的 `9eb6bc4`；本轮没有推送、远端合并或部署。

## 交付行为

教学楼首层门厅与示范教室、图书馆、自习室与庭院连续可走。教学楼/图书馆 E 开门后步行进入，自习室沿朝庭院的开放门洞进入；室内自动第一人称，出屋恢复第三人称。“回庭院”走实际路线；打开业务暂停移动，关闭恢复原站位。

| 空间 | 复用的模型和已接互动 |
| --- | --- |
| 教学楼 | 原可编辑建筑、24 个座位、课程板、讲台；三门本地示范课和笔记、正式题库入口、卷帘/灯光/投影 |
| 图书馆 | 原完整建筑和家具、8 个阅览位、四类书架、检索台、导读书和展示；原目录/PDF/书签摘记/推荐/阅读计时 |
| 自习室 | B 原房间、屋顶、家具、门洞与物件；E 拿书放回、Q 翻页、右键/按钮细看、G 放下（兼容 R）、C 坐起、签到台打开真实房间列表 |
| 社交广场 | 朝庭院服务台和留言板，分别接原好友/留言功能；保留原场景其他互动 |
| 竞技场 | 原模型、纸条、锣和竞技入口；打开原报名/好友挑战业务 |
| 庭院 | 原喷泉开关、座椅、导读书、导览和返回网站 |

原课程记录仍用 `xuewuyou-academy-v2`，书签和资料由原图书馆模块处理，账号、好友与留言等复用原主站；没有另建云存档或数据库。原独立场景入口保留。

## 接入方式

- `src/interiors.js` 直接复用原教学楼/图书馆建筑代码，不将空壳 GLB 叠在家具外。玻璃门、分隔门、桌椅、书架碰撞使用原数据转到世界坐标；门洞有人时不允许关闭门扇。
- 公共校园只有一个 Three.js 渲染器、一套输入/相机和动画循环。B 的原 `pick.js` 增加可选 `externalInput`，默认独立页行为不变；公共宿主管键盘与鼠标，避免双重触发。
- 图书馆 `campusPanel` 模式只初始化原 catalog、reading-shelf、reading-activities；移除其画布且不启动独立 3D app。PDF 的二维 canvas 不计作第二个 WebGL 场景。
- 原业务 iframe 使用 `embedded=campus`；关闭时卸载文档。图库面板消息校验同源、当前 iframe window 和随机 channel，过期加载由 generation 拦截。Esc 先关内层真实自习设定，再关闭宿主面板。
- 原作者依赖 `@dgreenheck/ez-tree@1.1.0` 固定版本；MIT 许可归档在宿主 licenses。公共宿主不创建其原预览场地树林。

## 实测证据

在本地隔离预览服务 `http://127.0.0.1:4184`，使用 Edge / D3D11 headless。以下报告均来自本轮最终构建：

| 报告 | 结果 | 验证重点 |
| --- | --- | --- |
| `interiors-validation.json` | 28 项通过 | 实际 W/E 进屋、闭门碰撞、教室设备/答题/坐位、真实 PDF/书签/计时、自习拿书翻页/坐起/走出、签到与社交竞技入口、390px、缺失资源 |
| `lifecycle-validation.json` | 29 项通过 | 五处真实步行路线、原跳跃、五轮业务开关/稳定 GPU 资源、原设定弹窗两级 Esc、触屏行走、五轮网站返回/后退、独立图书馆、Pages 子路径 |
| `quality-validation.json` | 8 项通过 | 精细/流畅/窄屏渲染路径、五轮切换资源稳定、实际行走帧间隔、资源与 shader |
| `courtyard-validation.json` | 15 项通过 | 流水、座椅、导读书、实际导航和手机导览 |
| `site-exit-validation.json` | 6 项通过 | 实际步行至出口、回网站、票据清理范围、加载时出口和 Pages 路径 |
| `round-validation.json` | 11 项通过 | 白石铺地、圆形水池碰撞、原竞技更新/纸条和窄屏 |
| `social-validation.json` | 10 项通过 | 服务区朝向、碰撞、真实步行操作好友与留言面板 |

合计 107 项浏览器断言通过，报告中的浏览器错误与缺失资源列表均为空。另有导航/返回状态单元检查、`npm run check --prefix server`（前端语法35文件、引用检查）通过。

本地隔离后端 `community-friend-e2e.js` 的双账号 HTTP 回归 16/16：注册、资料、好友邀请/接受、双向好友列表、留言发布/跨账号读取/再次读取/删除、越权403和未登录401。仅测试隔离目录，不使用线上账号；没有重启服务器验证持久性，也没有将 HTTP 回归当作全部双浏览器 UI 验收。

画质自动模式本机采样约6.2秒：680个帧间隔，中位8.4ms，P95 17ms，最大31.4ms；五轮画质切换保持1068个几何、144个纹理。数据用于本机回归，不代表真实手机帧率或长期堆内存。

Windows 本机 Node 存在 libuv 定时器异常，浏览器测试用 D 盘官方 Node 22.14.0 和单 CPU 亲和性运行，未修改服务器亲和性。复现脚本在 `js/features/campus-hub/tests/`，常规入口为 `npm test --prefix js/features/campus-hub`。

## 当前边界

首层门厅和现有一间教室可以进入；教学楼上层没有新增房间或楼梯通行。座位是本地选位，不是多用户独占占座。阅读计时只在本次面板内运行，不计云端学习记录。竞技接的是原报名与好友挑战，没有新增实时对打、NPC 或命中判定。未重新烘焙全校园光照，未完成整校照片级、实体手机性能、线上部署或长期稳定性验收。
