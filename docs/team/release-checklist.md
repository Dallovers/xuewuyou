# 发布与回滚清单（A07）

冒烟检查是可执行的脚本，不是一份需要人工核对的清单：

```bash
cd server
npm run smoke http://127.0.0.1:3000                      # 本地
npm run smoke https://xuewuyou-campus.onrender.com       # 线上
npm run smoke <url> --read-only                          # 只读，不建临时账号
```

全部通过退出码 0，有任何失败退出码 1，可以直接串进发布流程。

## 冒烟覆盖的路径

| 检查项 | 失败意味着 |
|---|---|
| `/api/health` 可达 | 服务没起来，或免费实例还在冷启动（脚本会自动重试约 30 秒） |
| 题库元信息可读、不含答案 | 公开接口泄露题目内容 |
| 未登录访问受保护接口返回 401 | 鉴权面被改坏 |
| 注册 + 学习记录同步 | 数据库或用户数据链路异常 |
| 断点续学：建会话 / 存进度 / 过期版本 409 / 恢复位置与草稿 | 续学链路或冲突语义坏了 |
| 校园八地点状态 | 状态适配层异常 |
| 世界存档 + 越界坐标被拒 | 位置校验失效 |
| 自习统计边界（100000 分钟被拒） | 上报上限失效（见下「依赖」） |
| 题目分发默认不含答案 | 题目接口泄露答案 |

**依赖**：最后两项里的「自习统计边界」需要「单日上限」修复已合入（PR #7）。在该修复合入前，冒烟会在这一项报红——这是**预期行为**，说明线上还缺这个修复。

## 环境

| 环境 | 入口 | 说明 |
|---|---|---|
| 本地 | `cd server && npm start` | 需要 Node ≥ 22.12；Python 学习引擎见下 |
| CI | GitHub Actions `verify` | 安装依赖 → 语法检查 → 全量测试（含真实 PostgreSQL）→ 容器内验证 pyBKT / OR-Tools |
| 线上前端 | GitHub Pages | 纯静态托管，不连后端也能用本地模式 |
| 线上后端 | Render 免费实例 | 会休眠，首次请求约 1 分钟 |

本地想要跑通全量测试，需要先装 Python 学习引擎（否则约 7 项会红）：

```powershell
powershell -File services/Setup-Learning.ps1
```

装好后本地应看到 `# tests 98 / pass 95 / fail 0 / skipped 3`（3 项是 PostgreSQL 用例，本地无测试库时跳过）。

## 回滚

### 代码

```bash
git revert -m 1 <merge-commit>     # 回滚某次合并
# 或重新部署上一个通过的提交
```

### 数据

本次各 PR 的改动都是**新增字段或子键**，没有修改既有结构：

- 断点续学：`learning.practice`（新键）
- 世界存档：`learning.world`（新键）
- 题库过滤：只在读取时跳过，不改题库文件

因此**回滚代码不需要数据迁移**：旧代码不认识这些键，直接忽略即可。反过来，如果先回滚再恢复，数据仍在。

### 题库

坏题是否进池由 `KNOWN_DEFECTS` 驱动。把某一行从登记表删掉，该题立刻回到题目池，不用改任何逻辑代码。

### 回滚后确认

```bash
npm run smoke <url>
```

冒烟一旦通过即可认为回滚完成；`node --test test/*.test.js` 用于确认行为没有退化。
