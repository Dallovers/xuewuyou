# 你负责的 3D 美术参考与生图清单

本轮目标改为真实 3D。你的图片用于确定构图、建筑/角色外观和材质参考；C 负责把参考制作/适配成能运行的模型、动画、碰撞与导航数据。单张透明建筑 PNG 不能直接充当最终 3D 建筑。

## 出图顺序与交付

| 顺序 | 你交付 | C 配套交付 |
|---|---|---|
| 1 | 校园总览概念图，注明道路、桥、台阶、八地点意向 | 带高差与可达路线的 3D 灰盒；先一起确认能走通 |
| 2 | 学院与图书馆的同尺度正/侧/背/顶视图 | 两个可运行 GLB 样例，试放比例、光照、性能与入口 |
| 3 | 一个角色的正/侧/背参考、衣服颜色与比例 | 角色模型、骨骼绑定、idle/walk/run 动画与控制器 |
| 4 | 剩余六地点的建筑参考，按已确认规范补 | 自习馆、草稿屋、社交会馆、竞技馆、错题工坊、成长塔的模型 |
| 5（可选） | 石砖、屋瓦、道路等无缝材质参考 | 调整纹理、材质与压缩，不把生图阴影误当真实光照 |

已有[海岛](../../vendor/atlas-art/campus-handpainted.png)和[图书馆](../../vendor/atlas-art/library-handpainted.png)可做风格参考：石砖、蓝灰屋顶、暖窗、树木与水。先不批量画七张等距透明 PNG，以免和真正建模需要的参考不匹配。旧 PNG 与 2D 地图可保留作回退。

## 提示词：校园概念图

> 参考所附海岛和石砖图书馆，设计一个用于浏览器轻量 3D 学习游戏的校园海岛概念图。温暖石材、蓝灰屋顶、清晰植被和水面，风格化低面数建模可实现的体块，精致但克制。八处用途不同的建筑用清楚轮廓区分：学院、图书馆、自习馆、草稿工坊、社交会馆、小竞技馆、错题修复工坊、成长塔。校园有连贯可步行主路、少量高度变化、一座桥和宽台阶，各建筑门口连接道路；道路和建筑轮廓清楚，不被大树遮住。斜俯视总览，用于布局与建模参考，非界面截图。不要文字、按钮、功能面板、进度条、水印，不要悬空断路或无法通行的细窄桥。

图生成后由你/C 人工标注地点和高差；生图本身不能证明路径实际可达，最终以灰盒为准。

## 提示词：单栋建筑多视图

> 参考所附图书馆的材质与色彩，设计【建筑名称及轮廓特征】的 3D 建模参考图。统一风格化比例，石砖墙、蓝灰屋顶、少量藤蔓、温暖窗户，主体体块清楚、适合轻量游戏。提供同一栋建筑的正面、右侧、背面、屋顶俯视四个严格正交视图，各视图比例一致，门窗与烟囱的位置对应，屋顶结构自洽。中性浅灰背景，均匀无强方向光，不画夸张投影，不裁切建筑，不带大块景观底座。不要透视变形、景深、文字、尺寸标注、按钮、人物、水印。

生成后检查四个视图一致性；对不一致处由 C 固定结构，不能让建模依赖互相矛盾的参考。

## 提示词：玩家角色

> 为温暖石砖校园海岛 3D 学习游戏设计一位大学生角色的建模参考。风格化自然比例，轮廓清楚，简洁外套、长裤、运动鞋，配色与蓝灰屋顶和暖石色协调；衣饰简洁便于实时渲染与骨骼动画。展示同一角色正面、侧面、背面，统一尺度与中性 A pose，手臂稍离身体、手指和双腿可区分，头发结构简洁。中性灰背景，均匀光照，无透视夸张。不要文字、UI、武器、复杂飘带、遮挡身体的大背包或水印。

角色参考图不等于已绑定模型，骨骼与动画由 C 完成。若 C 使用授权清楚的现成角色，先确认兼容性，你只需确定外观方向。

## 可选材质提示词

> 风格化游戏用【浅暖石砖/蓝灰屋瓦/校园石路】无缝平铺颜色纹理，正对表面，均匀中性光，细节适中，适合轻量 3D 校园场景。不要透视、文字、明显方向阴影、高光、物体或场景边界。输出方形图片，四边可连续衔接。

生成纹理须实测拼接；颜色图不等于完整 PBR 材质，法线/粗糙度由 C 处理。你交原图、版本、参考来源；压缩、命名、模型、碰撞、导航和网页加载交 C。
