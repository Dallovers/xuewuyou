# 你负责的地图生图清单

先保留现有海岛、手绘花园和图书馆。当前最有收益的是补齐建筑，不必先重画整张地图。

## 出图顺序

1. 把现有[图书馆](../../vendor/atlas-art/library-handpainted.png)和[海岛](../../vendor/atlas-art/campus-handpainted.png)作为参考图，先做“课程学院”和“自习馆”。
2. 交给 C 试放，确认视角、大小、光源和底座一致后，再生成剩余五张。
3. B 检查与全站界面是否协调；C 压缩发布图片和配置坐标，你保留原始 PNG。

## 统一规格

- 每张 1024×1024 或 1536×1536，**真正带透明通道的 PNG**。棋盘格/黑底/白底画在图片里，不等于透明。
- 建筑完整不裁切，主体居中约占画面八成；脚下只保留紧凑台阶/底座，不画大块草坪。
- 与图书馆保持相同俯视角度，正面和右侧可见，左上方柔和日光。
- 石材、砖墙、蓝灰屋顶、温暖窗灯保持统一；用轮廓和局部装饰区分用途。
- 不画中文、数字、功能按钮、进度条、人物、水印；名称与数据全部由网页叠加。
- 不在图片里画“已完成/未解锁”状态。C 用真实学习状态叠加，后续换图不影响功能。

## 可直接复制的通用提示词

> 以提供的手绘图书馆和海岛为视觉参考，生成一座独立的【建筑主体与辨识特征】，用于大学生学习平台的手绘校园冒险地图。与参考图保持一致的俯视角度，正面和右侧可见，左上方柔和日光。精细水彩与不透明水粉质感，可信的石砖结构、蓝灰瓦顶、温暖窗灯、少量藤蔓，比例端正，细节适合缩小展示。建筑主体完整居中，屋顶、墙体、台阶都不裁切，脚下只有紧凑石台和短阴影。1024×1024，真正透明背景 PNG，画面外围透明，主体约占八成。不要大块草坪、天空、海洋、独立岛屿，不要文字、字母、数字、招牌字、人物、按钮、进度条、商标或水印，不要把棋盘格画进图片。

将表格最后一列替换进【建筑主体与辨识特征】，每次只生成一座建筑。重点检查缩小后是否仍能从轮廓区分，不必把细节堆满。

## 如果后续确实要重画底图

校园图比例保持 3:2，建议 3072×2048 原图。先让 C 提供八个落位的参考图再生成，保留空地和道路，不把建筑和功能名焊死在底图里。当前落位顺序见根目录[地图素材指南](../../地图美术素材指南.md)。

课程/章节图使用 1080×680 逻辑画布，可交付 2160×1360；中央保留足够留白给不同数量的节点。它们已有手绘花园，不是本轮第一批必交素材。

交付给 C：原图、建筑名称、版本号和你选择的参考图。文件压缩、透明通道检查、锚点/坐标、加载回退由 C 负责，你不需要手算画布坐标。
