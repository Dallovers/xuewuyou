# 队友 B：全站界面与体验

集中负责页面的结构、视觉和可操作性。A 做认证/学习业务与续学，C 做 3D 场景及地图操作面板；你无需兼任这两套功能的实现者。

## 任务与完成标准

| 编号 | 工作包 | 完成标准 |
|---|---|---|
| B01 | 规范与两个样板 | 先做首页外壳、真实题目页的桌面/手机样板；确定字阶、间距、颜色、字体、图标、按钮与状态样式，再扩全站 |
| B02 | 页面与弹层 | 登录、首页、课程/章节、练习、自习、资料、错题、报告、复习、问答、社交、AI；包括白板外壳、留言编辑/详情、个人自习设置、确认/错误弹层 |
| B03 | 布局与内容层次 | 题目适合阅读作答；资料适合搜索；报告解释实际记录；自习突出计时和成员；社交保留便签墙但正文/回复清楚。不让每页长成相同卡片堆 |
| B04 | 状态与反馈 | 加载、唤醒等待、空数据、失败、未配置、权限不足、提交中都有对应状态；使用 A 提供的真实数据，文案说明具体动作 |
| B05 | 适配与可访问性 | 320/375/390/768/1440 宽度；键盘、长公式/题目/昵称/留言、可见焦点、至少 44px 主要触控区、减少动态效果 |
| B06 | 统一集成 | 管 HTML/脚本导入与全局样式；与 A 对齐 DOM/状态/事件，与 C 对齐画布容器和弹层边界；每次只导入已合入文件 |

## 视觉方向落到细节

- 现有海岛、蓝灰屋顶、石砖与温暖窗光可作为世界参考。标题适当有识别度，题面、解析与长文用清楚的正文系统。
- 减少通用口号、重复大横幅、每块都发光的描边、过多金色按钮；用真实课程和操作信息组织页面。
- 图标统一为 SVG 系统，逐步替换结构性 emoji；用户输入不限制。字体继续自托管，不堆多套库。
- 页面可保留新颖构图，题目/表单/列表保持阅读与操作清晰；不能用隐藏溢出来掩盖手机破版。

## 文件边界与工作减负

你负责 `index.html`、全站 CSS、`js/ux.js`、`js/campus-interactions.js`、品牌/字体/通用图标。`css/world-3d.css` 和 `js/world-3d/**` 归 C。

`js/app.js`、题库与功能业务脚本归 A。需要变更它们时，提交具体模板/选择器/事件需求给 A；不要为一个样式调整重写业务层。C 自行实现地图摇杆、加载进度、目的地提示和镜头按钮，你提供设计 token 并检查一致性。

保留题目反馈、全屏自习、白板、公式等既有功能；整理基础/校园/冒险叠加样式时分步回归。交付页面与状态清单、桌面/手机对照图和组件规范。用真实数据和空数据都验一次。
