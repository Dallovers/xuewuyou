# 队友 B：前端与体验

你负责全站结构、信息层次与操作体验；美化范围包含表单、题面、数据、列表、状态、导航和弹层，不局限于背景与按钮。

## 必做任务

| 编号 | 任务 | 完成标准 |
|---|---|---|
| B01 | 视觉规范与样板 | 保留手绘校园世界；先完成首页、实际题目页的桌面/手机样板。统一颜色、字阶、间距、圆角、图标与按钮层级，再扩展到全站 |
| B02 | 页面与弹层 | 登录、首页、课程/章节、练习、自习、资料、错题、报告、复习、问答、社交、AI；加上个人自习设置、白板、留言编辑/详情、确认和错误弹层 |
| B03 | 降低模板感 | 用页面真实任务决定布局；减少每页重复的大横幅、金色边框、渐变、自动扫光和口号。装饰集中在地图/入口，正文与频繁操作保持清楚 |

## 页面差异要落到内容

- 地图：地点可辨认，选中后明确展示“是什么、学习状态、能做什么”。
- 练习：题目、作答、提交反馈、解析、白板、上一题/下一题关系清楚；数学与长文不用装饰字体。
- 资料：搜索/筛选、可读/外链/不可用状态、条目层次和返回位置。
- 报告：先解释真实数据与下一步；无记录时给可执行入口，不用空图表装成果。
- 自习：计时、房间成员、状态和房主操作优先；个人自习手机按钮不能挤成竖排。
- 社交：搭子、留言、竞技保持同一产品语言，便签正文与回复不因美术变难读。

## 去掉“AI 痕迹”的具体做法

1. 文案减少“探索无限可能”等通用口号，优先说明当前课程、状态与动作。
2. 不把所有区域都做成相同卡片；使用列表、分区、阅读栏、表单和必要的对比布局。
3. 图标统一使用一套可控的 SVG 风格，逐步替换结构性 emoji；用户留言里的 emoji 不受限制。
4. 开源字体继续自托管，标题和正文职责清楚；不追加多套字体和动效库堆效果。
5. 先解决对齐、行距、对比度、长文本和错误恢复，再加装饰；不靠隐藏溢出来“通过手机适配”。

## 文件与交付

负责 `index.html`、`css/**`、`js/app.js`、`js/ux.js`、`js/campus-interactions.js`。现有基础、校园主题、冒险主题之间存在叠加关系，整理时需保留题目反馈、全屏自习、白板、公式和可访问性规则。

不整体重写后端，不直接改 C 的地图算法或学习状态。不提前引用未合入的新脚本。新增功能 DOM/样式与 C 先写清类名和状态契约。

交付：全页面/状态清单、桌面与手机前后对照截图、组件规范、文案与交互问题清单。用真实数据与空数据各验一次，不能只有漂亮的演示截图。
