## 第一轮事实与目标

- 当前地图是 2D，人物移动主要是到目标点的直线补间，不具备真实地形行走。本轮最终目标是 3D 模型、地面高度和可行走区域，不能用平面背景上的人物贴图验收。
- 数学题库有 1,823 条收录记录、1,793 个不同题号；30 个题号跨章节重复出现，同题号题面相同，可能属于综合章节复用，不应直接当成错误删除。另有 7 条选择题缺少结构化答案，必须核查实际判题路径。
- 薄弱章节包括大数定律与中心极限定理 13 条、假设检验 17 条、特征值与特征向量 29 条、参数估计 30 条、相似对角化 31 条。四六级和雅思目前主要是词汇/替换练习，需要补真实题型，见[题库计划](question-bank-plan.md)。
- 上轮检查：`npm run check` 通过；38 项测试中 36 通过、2 项 PostgreSQL 测试未指定测试库而跳过。公网健康接口曾测得 41.32 秒和 6.64 秒响应，根因尚未确定。健康接口成功不等于数据库和全部业务正常。

## 质量边界

目标是已知可复现问题清零、关键自动化通过、上线后再次验证。现有真实多人自习继续保留；本轮地图先做单人角色，地图多人同屏另排，不默认加入 MMO。地图映射真实学习记录，但没有校园测绘与状态同步依据时，不宣传为实体校园的数字孪生。不恢复已删除的学习工作台。

模型、RAGFlow、MinerU 等外部能力按真实配置展示；密钥不进 Git，不用生产库跑破坏性测试。题库、模型和贴图都保留来源与可用授权。
