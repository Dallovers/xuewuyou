# 学无忧 · 三人协作入口

2026-10-19 起采用按完整功能板块负责的三人分工。旧四人技术岗位分工保留为历史参考，当前以本页和新执行单为准。

| 负责人 | 完整板块 | 本轮 3D 与业务交付 |
|---|---|---|
| A | 好友与社交广场，后续扩展好友竞技场 | 好友申请/确认、留言与对应亭廊、服务台、公告栏、喷泉等 |
| B | 个人与多人自习室 | 公开房间/共同计时、个人专注及对应自习空间、桌椅、入口、计时牌 |
| C：项目负责人 Dallovers | 图书馆与校园总装 | 资料分类/阅读、图书馆；公共移动/相机/碰撞、统一材质、渲染和集成 |

## 项目负责人给 A/B 的协作约定（当前生效）

> 如果你们做出的模型或渲染效果不好，直接发给我（项目负责人 Dallovers），我可以帮你们修改。请同时提供可编辑源码/模型、复现步骤和问题截图，不要只发一张效果图。
>
> 项目所有生成的图片统一由我生成和提供，包括概念图、建筑/室内参考、多角度图、材质参考和用于项目的生成贴图。你们不用配置生图工具；有需求直接跟我说，写清板块、用途、对象和视角。未经确认，不自行用其他生成图替换公共参考或材质。

已有模型、材质、贴图和开源资源可以依约复用，保留来源；浏览器/Blender 实际渲染截图是检查材料，可以自行导出，不属于需要另行生图的工作。各板块负责人继续完成自己的布局、业务和 3D 修改，负责人集中协助效果改善。

## 从这里开始

1. 阅读 [三人按功能板块分工执行单](three-person-feature-plan.md)，末尾有可直接转发给 A/B 的任务说明。
2. 运行 [课程学院真实 3D 参考 v5](../../examples/campus-3d-v5/README.md)：已构建，无需安装 Blender 或 npm 依赖；看源码和交互也从这里开始。
3. 对照 [A/B 风格样板](visuals/ab-style-v1/README.md)，先做一个代表性构件，统一检查后扩展完整空间。
4. A/B 以自己的独立板块推进；C 先用占位空间总装，不等某一板块完全精装才开始。

3D 参考是独立示例，不代表主站已经接入全校园 3D；示例练习和本地笔记也未接主站真实账号。主站既有学习/好友/自习业务继续保留。
