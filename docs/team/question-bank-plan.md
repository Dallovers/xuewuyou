## 分批目标（开发目标，尚未完成）

1. **先清洗**：稳定题号、章节关联、答案字段、题面公式、来源、旧题兼容；输出实际可用数量及问题隔离清单。
2. **首批扩充**：数学新增至少 300 道有效独立题，优先上表；英语新增至少 120 个非纯背词的阅读/完形/语法小题，四六级/雅思适用范围分别标注；另补 20 个有评分说明的写作任务。阅读按小题计数，同时统计原文篇数，不能把同一材料包装成多套。
3. **后续完整目标**：数学独立题达到至少 3,000，所有现有核心知识点至少 60 道有效题；四六级与雅思继续按题型缺口扩充。具体来源和审校产能确认后排期，不承诺未经审校的一次性灌库。

未配置真实评分服务时，写作提供任务/评分维度/参考分析，标明自评或待评，不能伪造考试分数。听力必须有可用且许可明确的音频、文本和答案，不能只有听力标题。

## A 要交付的数据工程

- 统一格式：稳定 ID、题库版本、科目/章节/知识点、题型、难度、题面/选项/答案/解析、素材引用、来源及可用授权、审校状态；不适用字段明确为空，不用臆造数据填满。
- 导入流程：JSON/CSV → 结构校验 → 去重/相似候选 → 人工审校 → 小批预览 → 版本发布；失败隔离并报告，不把错误题默默混入正式库。
- 审核答案确实属于选项、选项无无意义重复、公式可显示、解析支持答案、条件完整；计算题能自动验证的增加独立校验，不能用同一段生成逻辑自证答案。
- 参数化生成题须标明模板与参数，保证合法域、答案正确和变式差异；题数报告单列模板/变式数量，不把换数字都叫全新知识点。
- 保留旧 ID 与迁移映射；题库换版不破坏错题、白板、续学、报告与挑战复盘。删除题目可读旧题快照或给明确失效状态。
- 正式发布新增题逐题有校验记录；B/C 交叉抽查公式/题面与高风险答案，抽查发现错误时回到同批次排查。待审题不进入正式组卷。
- 输出每科/章/难度/题型覆盖、独立题数、复用记录数、题源、异常数；后台或 CLI 有导入/回滚工具即可，首轮不要求 B 再做大型管理后台。
